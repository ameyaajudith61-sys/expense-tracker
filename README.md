# Expense Tracker

A small command-line expense tracker written in Python. Add expenses, view the recorded expenses, and calculate total spending with a breakdown by category. Amounts are displayed in Ghana cedis (₵).

## Requirements

- Python 3

## Run

From this folder, run:

```bash
python project.py
```

The app saves expenses in `expenses.json` in the current working directory. This local data file is intentionally excluded from Git so personal spending data is not uploaded.

## Menu

1. Add an expense with a description, amount, and category.
2. View all recorded expenses.
3. See total spending and totals by category.
4. Exit the app.
